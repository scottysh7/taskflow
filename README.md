# 📱 TaskFlow - Gestionnaire de Tâches Collaboratif

Application de gestion de tâches avec version web et mobile.

## 🛠️ Stack Technique

- **Frontend Web:** React + Vite + Tailwind CSS
- **Frontend Mobile:** Flutter
- **Backend:** Supabase (PostgreSQL + Auth)
- **Hosting:** Vercel (Web) + App Stores (Mobile)

## 📦 Structure du Projet
```
taskflow/
├── backend/     # Configuration Supabase
├── web/         # Application React
├── mobile/      # Application Flutter
└── docs/        # Documentation
```

## 🚀 Développement

### Web
```bash
cd web
npm install
npm run dev
```

### Mobile
```bash
cd mobile
flutter pub get
flutter run
```
